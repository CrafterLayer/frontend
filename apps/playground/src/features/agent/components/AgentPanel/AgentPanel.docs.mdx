# AgentPanel

The agent panel's composition root (SPEC §4.1, §7.2 #51): أبو غضب's column in the editor's left
dock, 320px by default and resizable from 288 to 480, and its phone sheet.

<Canvas of={AgentPanelStories.Building} />

## Purpose

One place wires every component of `features/agent/` to one `AgentController`: the header, the
thread (records and cards through TurnView), the dock with the composer, Conversations, the one live
region and the resize separator. It adds no copy of its own; the region is named by the header.

## When to use / not

- `LiveAgentPanel` is what the app mounts: `useAgentController` over the host's kernel, provider and
  capabilities, then `AgentPanel`.
- `AgentPanel` takes any `AgentController`: the stories and tests pass the fake one.
- Not for the source-code agent (`SourceAgentPanel`); it adopts these components in a later spec.

## Props

| prop            | type                          | default | notes                                                                |
| --------------- | ----------------------------- | ------- | -------------------------------------------------------------------- |
| `controller`    | `AgentController`             | none    | state and every action                                               |
| `visible`       | `boolean`                     | `true`  | hidden keeps it mounted, pauses the ticker; the pill speaks for it   |
| `width`         | `number`                      | 320     | px, clamped to 288 to 480; uncontrolled when left out                |
| `onWidthChange` | `(width) => void`             | none    | the separator moved; the host resizes its column                     |
| `presentation`  | `'auto' \| 'dock' \| 'sheet'` | `auto`  | `auto`: the sheet below 600px on a coarse pointer                    |
| `onClose`       | `() => void`                  | none    | the sheet's `[×]` or Esc: the host hides the panel                   |
| `returnFocus`   | `() => HTMLElement \| null`   | none    | the rail's agent button, focused when the sheet closes               |
| `pillContainer` | `Element \| null`             | none    | an element in the status bar the pill is portalled into while hidden |
| `onOpen`        | `() => void`                  | none    | the pill was activated                                               |
| `tooltipDelay`  | `number`                      | 500     | tests pass 0                                                         |

`LiveAgentPanel` takes every `UseAgentControllerOptions` field (`kernel`, `locale`, `provider`,
`providerKind`, `addPage`, `selection`, `editModel`, `editEffort`, `models`, `model`,
`onSelectModel`, `onPreview`, `onViewAsCode`, `onOpenPageHistory`, …) beside these, plus
`onSiteSeam` for the Site destination's run lease.

## States

`data-state` on `.ck-agent-panel`: `idle`, `running`, `stopping`, `awaiting-decision` (a ready plan,
step plan or proposal), `hidden`. Stories cover every SPEC §3 frame the fake controller draws: empty
(3.1), composing and mention (3.2), skeleton, building, blocked, built, partial (3.3 to 3.5), edits
(3.6), plan and Ask (3.7, 3.8), queue, stopping, stopped, error (3.9 to 3.11), long (3.12),
Conversations (3.13), 420px (3.14), Arabic (3.15), the phone sheet (3.16), Improve and clarify, and
hidden with the pill.

`ShortViewport` covers a 288px-wide, 400px-high editor with a long conversation;
`ShortViewportClarifyingArabic` covers the same constrained height with Arabic questions in dark
chrome. Their plays measure usable thread/field/toolbar geometry rather than relying on screenshots.

The column is a size container for bounded auxiliary composer content. The thread retains its own
scrolling area, the dock uses a small separating gutter, and hidden mounting preserves drafts,
reading position and the captured run. Questions scroll separately; the composer itself does not
clip its popups or controls.

## Dropping data

A .csv, .tsv, .md or .txt file dragged over the panel shows a dashed hint ("Drop a CSV, TSV or
Markdown table to chart it"). Dropped, its rows go into the draft under "Chart this:" (or under the
person's own words), the line the zero-token chart path reads. Sent as it is, the rows become a
Chart or Table block with no model (`data.show`). Any other file, or one over 20 KB, is refused in
the same place for three seconds, and no dropped file ever opens in the tab (`useDataDrop`).

## Accessibility

- One region, named by the header's `h2` (`aria-labelledby`). Exactly one `aria-live` element.
- The separator: `role="separator"`, `aria-orientation="vertical"`, `aria-valuemin` 288,
  `aria-valuemax` 480, `aria-valuenow`. ← → 16px, Shift 48px, Home / End, in visual direction.
- Ctrl+. (⌘. on macOS) anywhere in the panel stops the live run; the composer spends it first.
- A suggestion fills the composer and puts the caret at its end; it never sends. Sending while
  scrolled up follows the thread to the newest line.

## RTL

The panel root carries the UI's `dir` and `lang` and sits inside Radix `DirectionProvider`; logical
properties mirror everything. The separator lives outside that `dir` and reads the editor's: an
Arabic panel docked in an English editor keeps its outer edge, and its separator, on the right.
`.ck-agent, .ck-agent [lang] { font-family: var(--bldr-font) }` re-declares the family where a
language changes, since the family inherits as a computed value.
