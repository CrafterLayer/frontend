# ClarifyPanel

Questions before guessing: when a request is too unclear to act on, أبو غضب asks one to three short
questions, docked on top of the composer, instead of running the request as it read it.

<Canvas of={ClarifyPanelStories.Asking} />

## Purpose

The owner's own request («هل يمكنك تربط ال صفحه هاي داخل عليها») was taken literally. Now the agent
says what it understood, asks what it must know (which page, where, how it looks), and offers the
likely answers as chips, at most three questions and each with chips (`clarifyQuestionsOf`). A
confident, clear request is never asked (`needsClarifying`): the panel is for the unsure ones.

Every question is skippable, and the questions never stand between the person and a build (the
first-build research: Wix's Skip and "End chat & continue", dyad's few questions only when
ambiguous):

- **Skip** («تخطَّ») answers the question on screen with «اختر أنت الأنسب» / "Your call", so the
  rewrite fills it with a sensible default. Skipping the last open question when nothing was
  answered for real runs the request as written.
- **Build now** («ابنِ مباشرة»), on a request routed to a build (`clarify.builds`), skips every
  question left. With nothing answered for real it runs the request as written (no rewrite round
  trip); with some answers, the rest become "Your call" and the answers are kept in the rewrite.
- Any other request keeps **Send as written** («إرسال الطلب كما هو»).
- **Cancel** puts the request back in the box, unsent.

## Anatomy

The composer's first section, over a Hairline. It reads like a decision card's head: the Indigo
diamond (RunGlyph `decision`) on the glyph column, the title in Heading type, "1 of 3" in Figure
Slate at the inline end, and every line under it on the record's text column, 24px in. One question
at a time, so the panel stays short in a 320px column. Choices are chips: Tint and Graphite at rest,
Mist and Indigo deep with a check once chosen, 32px tall (44 on a coarse pointer). Build now is the
one Indigo (primary) button; Send as written is the secondary button (Rule border); Skip and Cancel
are ghosts. While the answers rewrite the request, Build now and Skip are gone.

## Accessibility

- A group named by its title. Progress is drawn "1 of 3" and spoken "Question 1 of 3".
- Each question's chips are a `radiogroup` named by the question; one roving tab stop. A pick
  commits, so the arrows only move: ← → ↑ ↓ in the reading direction, Home and End jump, Enter or
  Space picks.
- Focus moves to the first chip when it opens, to the next question after each answer, and to the
  working line while rewriting; the Composer returns it to the textarea when the panel goes.
- Other opens a field described by its question; Enter sends the answer, Esc returns to the chips.
- Build now is described by «يتخطّى بقية الأسئلة ويبني بخيارات مناسبة» / "Skips the remaining
  questions and builds with sensible defaults"; Skip is described by the question it skips. Both
  are ordinary tab stops after the radio group; a skip moves focus to the next question's chips.
- A skipped question, revisited, checks no chip: "Your call" is not one of its answers.

## RTL

The diamond at the right; ← moves forward. The owner's Arabic questions and chips are authored
Arabic, not mirrored English.

## Motion

Arrives with opacity and a 4px rise over 220ms. The rewriting line shimmers in the reading direction
(SPEC §5 moment 10). Reduced motion: none; the line stays Slate.
