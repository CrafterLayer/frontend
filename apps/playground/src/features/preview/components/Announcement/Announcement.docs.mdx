# Announcement

The playground's runtime-registration demo block: its type is pre-allowed by the page vocabulary,
but this renderer only enters the kernel when the demo extension registers at runtime — proving live
registration without reload.

## Props (intent-only)

- `message: string (1–120)`
- `tone: 'info' | 'success' = 'info'`

## Accessibility

A `role="status"` bar with readable text.

## Theming & RTL

Info tone uses accent tokens; centered text is direction-neutral.
