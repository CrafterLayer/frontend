# FixturePicker

Controlled select choosing the playground's fixture document (marketing landing, empty page, or the
B3c inline-editing document). Switching fixtures recreates the kernel — documents are data, kernels
are sessions.

## API

- `value: 'landing' | 'empty' | 'inline'`
- `onChange(next)`

## Accessibility

A native labelled `select`.
