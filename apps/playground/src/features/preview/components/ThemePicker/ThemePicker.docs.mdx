# ThemePicker

Controlled radio pair selecting the preview theme (`light`/`dark`). Pure UI state — theme is APP
state handed to the frame, never document data.

## API

- `value: 'light' | 'dark'`
- `onChange(next)`

## Accessibility

A `fieldset` with a legend; labelled native radios, keyboard-operable.
