# PersistenceStatus

`PersistenceStatus` reports what storage actually acknowledged. **Saved to this device** appears
only after the IndexedDB transaction completes. A successful request whose transaction later aborts
is reported as session-only or failed, never durable.

Saving and durable acknowledgements stay on one compact toolbar line. Session-only and failed
acknowledgements expand because the recovery reason and actions need room. The component uses the
builder chrome's panel background, text, border, warning, and danger tokens in both light and dark
themes.

Session-only and failed states explain the browser reason and expose recovery actions supplied by
the host. **Download project** should use `createSiteSourceDownload`, which serializes the authored
site and preserves source text even when TSX is temporarily invalid. **Retry storage** starts a new
save attempt; it does not discard or rewrite the open source.

The container is a polite live region while saving, durable, or session-only. Failures use an alert.
Actions are native buttons in reading order with visible focus from `ChromeButton`. The layout uses
logical properties, inherits LTR or RTL from its host, wraps below 560px, and consumes builder theme
tokens. Its pulse stops when reduced motion is requested.
