# Bento grid

A professional editorial grid for combining product capabilities, outcomes, and proof points in one
high-signal section. Its hierarchy is document data rather than positional CSS guesswork.

## Props

- `eyebrow?: string (1–40)`
- `heading: string (1–100)`
- `body?: string (1–240)`
- `items: Array<{ kicker?, title, body, metric?, size, emphasis }>` — up to 12 cards.
- `layout: 'mosaic' | 'equal' = 'mosaic'`
- Shared alignment, tone, spacing, width, colour, motion, typography, and logical spacing controls.

## Accessibility

The section is named by its visible `h2`. Cards are a semantic list and each card is an `article`
with an `h3`; the numeric label remains readable content rather than decoration.

## Responsive and RTL behavior

The grid is one column by default, then grows to six and twelve container-query tracks. Logical text
alignment and spacing work in both directions. The equal layout deliberately overrides item sizes so
every card has the same responsive span.
