# Carousel

A production-oriented content slider for product stories, destinations, campaigns, and featured
work. Every slide is always in the DOM, inside one scroll-snap track; a live (React) render shows
the active slide and hides the others, instead of moving a hidden strip with literal transforms.

## Published pages (no hydration)

The static export renders with `renderToStaticMarkup` and never hydrates, so React state cannot
run there. The static render therefore hands the block to the site behaviour runtime: the track and
the previous/next buttons sit inside an element carrying `data-ck-behavior="carousel"`, with
`data-ck-indicator="dots"` (or `none` when indicators are off) and, when autoplay is on,
`data-ck-autoplay="true"` and `data-ck-speed` set from `autoplayInterval`. The `carousel` behaviour
pack (`packages/builder/renderer/src/behaviors/packs/carousel.ts`) derives the buttons, builds the
dots and the pause/play toggle, and scrolls the track — in the published page exactly as in the
canvas. The React-only controls (direct indicators, play, the counter and the live status) are not
part of the static markup.

## Content contract

- `heading`, optional `eyebrow` and `body` introduce the section.
- Up to ten slides provide a title, optional label/body, optional safe image, and optional safe CTA.
- `variant` supports `card`, `split`, and immersive `media` presentation.
- `mediaPosition` and `mediaAspect` shape responsive media without changing content.

## Controls and autoplay

Previous/next buttons, direct indicators, Home/End, and direction-aware arrow keys are supported.
Indicator buttons retain a minimum 24-by-24-pixel target around their compact visual dot. Autoplay
is **off by default**. When enabled, keyboard focus always pauses it; pointer hover also pauses it
when `pauseOnInteraction` is enabled. The carousel exposes a pause/resume control and does not start
under `prefers-reduced-motion` unless the visitor explicitly presses Play. Intervals are named
design intents rather than values stored in the document.

## Accessibility

The labelled section declares the carousel role description. The active slide is a named group,
controls reference it with `aria-controls`, the current indicator uses `aria-current`, and a polite
status announces manual changes without announcing every autoplay tick.

## Safety, theming, and RTL

CTA destinations allow relative paths, fragments, HTTP(S), mail, or telephone links. Media allows
only relative and HTTP(S) sources; executable, protocol-relative, and slash-backslash URLs are
rejected by the schema. CTA anchors remain semantic but cannot navigate while the block is on the
builder canvas. A split slide collapses to one copy column when no media is present. All visuals use
token-backed utilities, logical alignment, and container queries. Arrow semantics and keyboard
direction adapt to RTL, while the numeric progress remains isolated in its natural `current / total`
order.
