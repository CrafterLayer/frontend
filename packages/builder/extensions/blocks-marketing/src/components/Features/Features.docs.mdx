# Features

A grid of feature cards driven entirely by document data.

## Props (intent-only)

- `heading: string (1–80) = 'Features'`
- `body?: string (1–200)` — supporting copy below the heading.
- `items: Array<{ title: string (1–60); body: string (1–160) }> = []`
- `columns: '1' | '2' | '3' | '4' = '3'`
- `align: 'start' | 'center' | 'end' = 'start'`
- `tone: 'transparent' | 'light' | 'dark' = 'transparent'`
- `spacing: 'none' | 'sm' | 'md' | 'lg' = 'md'`
- `width: 'narrow' | 'standard' | 'wide' | 'full' = 'full'`

## Accessibility

A labelled `section` with an `h2` heading and a semantic `ul` list; each card is a list item with an
`h3`.

## Theming & RTL

Tokens + logical properties only; alignment follows the document direction. Tone paints the full
section while width constrains its inner content. An empty `items` list renders its heading and
optional supporting copy with no placeholder rows.
