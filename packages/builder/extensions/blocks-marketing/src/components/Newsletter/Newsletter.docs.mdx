# Newsletter

A production-shaped newsletter signup section with native email validation, an editable submission
endpoint, and visible privacy context. Inline, card, and split treatments cover compact and campaign
layouts without changing the content contract.

## Props

- `eyebrow?: string (1–40)`
- `heading: string (1–100)` and `body?: string (1–240)`
- `emailLabel`, `placeholder`, and `buttonLabel`
- `privacy?: string (1–180)`
- `action: string = '/subscribe'`
- `variant: 'inline' | 'card' | 'split'`
- `formLayout: 'row' | 'stacked'`
- Shared section design controls.

## Accessibility

The form uses a programmatic label, native `type="email"` validation, autocomplete metadata, and a
submit button. When privacy copy exists, the email field references it with `aria-describedby`.

## Responsive and RTL behavior

The row form becomes horizontal only when its own container is wide enough; split presentation uses
the same rule. Logical alignment and spacing preserve reading order in RTL.

## Parts

Each inner element is a part (block-parts DESIGN §1): selectable and editable on the canvas, styled
per part through `partStyles`, and addressable by the agent by name, alias or label. Text and link
parts carry `dir="auto"`, so an English line on an Arabic page keeps its full stop at the end. Part
markers (`data-ck-part`, `data-ck-bind`) exist on the canvas only.

| name         | kind | bind          | label (en / ar)                            |
| ------------ | ---- | ------------- | ------------------------------------------ |
| `panel`      | box  | —             | Panel / اللوحة                             |
| `eyebrow`    | text | `eyebrow`     | Eyebrow / الشارة                           |
| `heading`    | text | `heading`     | Heading / العنوان                          |
| `body`       | text | `body`        | Body / الوصف (multiline)                   |
| `emailLabel` | text | `emailLabel`  | Email label / تسمية البريد                 |
| `button`     | text | `buttonLabel` | Button / الزر                              |
| `privacy`    | text | `privacy`     | Privacy note / ملاحظة الخصوصية (multiline) |

`placeholder` is an attribute of the email input, so it stays an Inspector row.
