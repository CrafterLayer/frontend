# Promo banner

A high-emphasis campaign section for launches, seasonal offers, upgrade prompts, and featured
collections. It can remain copy-led or introduce responsive media without changing its action model.

## Content and actions

- `label`, `headline`, and `body` define the message hierarchy.
- Up to two actions accept primary or secondary emphasis and safe destinations.
- Optional media carries explicit alt text and can be hidden without leaving a placeholder.

## Design controls

- `variant`: `centered`, responsive `split`, or immersive `media` overlay.
- `panelStyle`: token-backed surface, accent, or inverse treatment.
- `mediaPosition`, `mediaAspect`, `padding`, and `radius` provide intentional composition choices.
- Shared colour, motion, typography, custom class, and logical spacing controls remain optional and
  do not rewrite existing documents with new defaults.

## Accessibility, safety, and RTL

The semantic complementary region is named by its visible headline. Actions are real anchors with
visible focus styles. Destinations reject executable and protocol-relative URLs; media accepts only
relative and HTTP(S) sources. Container queries and logical positioning serve LTR and RTL from the
same markup.

The block intentionally does not expose a cosmetic dismiss button. A trustworthy dismissal needs a
persistence contract and host-owned consent state; hiding content only until the next render would
be misleading behavior.
