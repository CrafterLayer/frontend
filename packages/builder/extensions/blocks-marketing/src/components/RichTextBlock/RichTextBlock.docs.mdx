# RichTextBlock

Free-form prose (milestone B3b): headings 2–4, bold/italic, safe links, and lists — stored as plain
JSON, validated strictly at the command door, and rendered through the renderer's zero-dependency
`RichText` component. The block declares ONE rich property (`content: richText()`) and ships ZERO
panel code: registering `richTextExtension` gives it a full rich editor in the inspector
automatically.

## Usage

```tsx
// In a document:
{ type: 'richText', props: { content: { type: 'doc', content: [...] } } }
```

## API

| Prop      | Type           | Notes                                          |
| --------- | -------------- | ---------------------------------------------- |
| `content` | rich-text JSON | whitelist-validated on write; tolerant on read |

## Accessibility & RTL

Semantic output (`h2..h4`, `ul/ol/li`, `strong/em`, real anchors); hostile link protocols are
neutralized to plain text; logical properties keep prose correct under RTL (see the RTL story).

## When not to use

Single-line text (a heading prop, a label) belongs to plain string props; structured layouts belong
to dedicated blocks — this block is for prose.

## Known limitations

- The B3b whitelist excludes tables, images, and embeds (future milestones).
- Rich responsive overrides are deferred; the content edits the base bucket.
