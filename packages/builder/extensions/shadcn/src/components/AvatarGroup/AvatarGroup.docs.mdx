# Avatar Group

A Builder-native adaptation of the shadcn avatar pattern for teams, collaborators, customers, or
attendees. It uses the package's existing Radix Avatar primitive for resilient image loading and
fallbacks while keeping all visual roles on Craftkit tokens.

<Canvas of={AvatarGroupStories.ProjectTeam} />

## Content and accessibility

- `people` contains up to 20 names, optional safe image URLs, and optional fallback initials.
- Initials are derived from the first and last name when they are not authored.
- The list has an editable accessible label and each list item exposes the person's full name.
- Decorative images and initials do not duplicate those names in assistive technology.
- `maxVisible` shows between 1 and 12 people; one final avatar announces the exact hidden count with
  a localizable `overflowLabel`.
- Avatar sources accept relative paths and `http` or `https` only. Executable, data, and
  protocol-relative URLs are rejected.

## Design controls

Authors can choose three sizes, four overlap levels, circle or rounded shapes, three token-bound
tones, logical start/center/end alignment, motion, and validated custom utilities. Overlap uses
negative `margin-inline-start`, so the visual stack reverses correctly with RTL direction.
