# Breadcrumbs

A semantic breadcrumb navigation trail adapted from shadcn/ui. It renders a named `nav`, an ordered
list, native links for ancestors, and exactly one final item with `aria-current="page"`.

<Canvas of={BreadcrumbsStories.Default} />

## Safe structure, not decorative text

Destinations accept relative paths, fragments, and HTTP(S) URLs only. Unsafe schemes never enter the
document. The current page must be the final item; when no item is explicitly marked, the last item
becomes current automatically. Separators are decorative and ignored by assistive technology.

## Responsive without losing context

Trails longer than four items can collapse their middle ancestors below the component's medium
container breakpoint. The first ancestor, immediate parent, and current page remain visible; the
complete trail returns when the container has room. Set `collapse` to `none` when every level must
remain visible.

## RTL and theme roles

Layout relies on logical order and spacing. The chevron mirrors in RTL while slash and dot stay
neutral. Default, muted, and inverse tones use CraftKit roles; inverse always pairs its ground and
ink and adds a token shadow for a finished navigation surface.

## Parts

Each inner element is a part (block-parts DESIGN §1): selectable and editable on the canvas, styled
per part through `partStyles` (a part's name styles every instance; `name@2` styles the third one
and wins), and addressable by the agent by name, alias or label. Text and link parts carry
`dir="auto"`, so an English line on an Arabic page keeps its full stop at the end.

| name        | kind | bind                             | label (en / ar)          |
| ----------- | ---- | -------------------------------- | ------------------------ |
| `items`     | list | `items`                          | Trail / المسار           |
| `item`      | item | `items.*`                        | Crumb / خطوة المسار      |
| `item.link` | link | `items.*.label` + `items.*.href` | Crumb link / رابط الخطوة |

The current page is a link part without a destination. `label` (the navigation's accessible name) is
for assistive technology only and stays in the Inspector. The hover title is a plain-string copy of
the label.
