# Pagination

A semantic page navigator for archives, search results, storefront collections, and custom
sequences. It supports a generated sibling range or an explicit list without changing the rendered
navigation contract.

## Generated mode

Set `currentPage`, `pageCount`, a sibling count from zero to two, and a safe URL template containing
`{page}`. Optional first/last pages and ellipses keep large collections concise. Previous and next
destinations are generated unless safe overrides are provided.

## Explicit mode

Provide labelled items with optional safe hrefs, current state, and disabled state. Previous and
next links are explicit in this mode, making it suitable for named or non-numeric sequences.

## Variants and theming

`full` renders the page range; `compact` renders previous/current-status/next. Small, medium, and
large controls combine with start, center, or end alignment and transparent, surface, or inverse
token treatments. Motion and custom utilities remain optional and validated.

## Accessibility and RTL

The block is a named `nav` containing a semantic list. Current pages use `aria-current="page"`,
unavailable destinations use `aria-disabled`, ellipses have assistive text, and previous/next links
carry relationship metadata. Arrow glyphs flip in RTL while page order follows document direction.

## URL and canvas safety

Only relative queries, paths, fragments, and HTTP(S) destinations are accepted. Executable and
protocol-relative URLs are rejected. Links preserve their hrefs but prevent navigation on the
builder canvas.
