# Progress

A production-safe determinate progress indicator adapted from shadcn/ui and bound to CraftKit's role
tokens. The visible label is also the progressbar's accessible name, while `value`, `max`, and the
computed percentage are exposed to assistive technology.

<Canvas of={ProgressStories.Accent} />

## Honest range handling

The schema rejects negative values and non-positive maxima. If imported content exceeds its maximum,
the renderer clamps both the visual fill and `aria-valuenow` to the declared range. This keeps the
spoken state aligned with the pixels rather than presenting contradictory progress.

## Token-bound variants and motion

Accent, success, and neutral use semantic role tokens, never fixed palette colors. The fill grows
from logical inline-start, so RTL needs no duplicate layout. Width changes use a short transition,
and `motion-reduce:transition-none` removes it for visitors who request reduced motion. A shared
Builder motion specification can also be attached without changing the progress semantics.
