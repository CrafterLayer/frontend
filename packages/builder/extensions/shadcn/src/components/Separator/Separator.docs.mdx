# Separator

A Builder-native adaptation of the shadcn separator pattern. It separates related regions without
introducing a second colour system or storing literal CSS values in the document.

<Canvas of={SeparatorStories.LabelledAccent} />

## Semantics and controls

- Every variant exposes `role="separator"` and the authored horizontal or vertical orientation.
- An optional visible label also becomes the separator's accessible name.
- `tone` selects subtle, accent, or inverse token roles.
- `style` selects solid, dashed, or dotted borders.
- `thickness` selects token-compatible hairline, medium, or strong borders.
- `spacing` uses the Builder spacing scale; horizontal separators use block rhythm and vertical
  separators use logical inline rhythm.
- Motion and custom utilities use the same validated contracts as the rest of the package.

Vertical labels rotate within a fixed token-sized column. Border placement uses logical
`border-inline-start`, so directionality remains correct in RTL.

## Parts

Each inner element is a part (block-parts DESIGN §1): selectable and editable on the canvas, styled
per part through `partStyles`, and addressable by the agent by name, alias or label. Text and link
parts carry `dir="auto"`, so an English line on an Arabic page keeps its full stop at the end. Part
markers (`data-ck-part`, `data-ck-bind`) exist on the canvas only.

| name    | kind | bind    | label (en / ar) |
| ------- | ---- | ------- | --------------- |
| `label` | text | `label` | Label / التسمية |

The separator is named through `aria-labelledby` by its visible label part, never a copy of its
text.
