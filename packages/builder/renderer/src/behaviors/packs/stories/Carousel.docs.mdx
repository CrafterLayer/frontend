# Carousel (behaviour pack)

`mountCarousel` (`packages/builder/renderer/src/behaviors/packs/carousel.ts`) is the `carousel`
behaviour, moved out of `runtime.ts` and extended. It is serialised into the published page's
`assets/ck-behaviors.js`, so the same bytes run on the canvas and on the published site. The
published `Carousel` block renders this markup in its static export.

## Markup: the parts are derived

The vocabulary has no `data-ck-carousel-prev/next`. The **track** is the first element child that
is not a button or a row of buttons. The **buttons** are every `<button>` inside the carousel but
outside the track: the first is "previous", the last is "next". The first button sits at the inline
start (the right in RTL), so it always means "back"; what flips in RTL is the physical scroll
direction. A step is 85% of the track's width, smooth unless the visitor prefers reduced motion.

## Indicators: `data-ck-indicator`

- `dots`: one button per slide, labelled «الشريحة ٢ من ٥» / "Slide 2 of 5". The current one carries
  `aria-current="true"`.
- `counter`: «٢ / ٥» / `2 / 5` in a polite live region.
- `none`, or no attribute: nothing.

The current slide is read from `scrollLeft`, normalised for RTL, where Chrome and Firefox report a
negative value. The end of the track always counts as the last slide.

## Autoplay: `data-ck-autoplay="true"`

- It advances one slide per `data-ck-speed` (slow 7 s, normal 5 s, fast 3.5 s) and wraps at the end.
- A visible pause/play toggle comes with it (WCAG 2.2.2).
- It pauses while the pointer is over the carousel, while focus is inside it, and while it is off
  screen. A counter stays quiet while it plays, so ticks are not announced.
- It never runs under `prefers-reduced-motion: reduce`, and never on the editing canvas.

## Canvas and dispose

On the editing canvas (`interactive: false`) the dots or counter are drawn but inert, so a click
selects the element. The disposer removes the built row and every listener, timer and observer, and
restores each attribute the host has not rewritten.
