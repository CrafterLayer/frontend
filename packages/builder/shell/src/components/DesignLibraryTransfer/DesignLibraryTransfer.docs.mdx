# DesignLibraryTransfer

Import and export a site's design system (style-manager DESIGN.md §G).

- **Export** downloads `{ format: 'craftkit-design', v: 1, designSystem, library: { palette, styles, fonts } }`
  as `<system-name>.craftkit-design.json`. Symbols and templates are content, not look, and stay
  behind. Pass `onDownload` to save it another way.
- **Import** reads a file and checks it before anything is asked: format and version, the design
  system's shape and legibility, the library's shape (palette, styles and fonts only) and every
  named style's classes against the live vocabulary. A refusal is shown and nothing is written.
- **Preview.** The person sees what changes: the system name, how many tokens, and per collection
  how many entries are added, changed or removed.
- **Merge or replace.** By default imported entries replace same-id ones and the rest stay. "Remove
  entries the file does not have" drops the rest, except entries a page still uses, which are kept
  and listed. Symbols, templates and site settings are never touched.
- **One transaction.** Import sends one `importDesignLibrary` labelled "Import design system · &lt;name&gt;";
  one Undo restores the previous design exactly.
