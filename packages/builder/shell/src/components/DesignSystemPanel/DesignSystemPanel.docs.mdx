# DesignSystemPanel

A site's design system, sectioned (style-manager DESIGN.md §G).

<Canvas of={DesignSystemPanelStories.WithLibrary} />

## Sections

- **Colours.** The nine colour roles (pick one in the grid, edit its value), then the **site palette**
  (free colours published as `--ck-c-<id>`; add, edit and remove) and the
  [PaletteRampEditor](?path=/docs/builder-shell-designsystem-paletterampeditor--docs), which
  generates 50–950 OKLCH shades from one brand colour with a contrast matrix.
- **Typography.** A family per role (sans, serif, mono) from the
  [FontPicker](?path=/docs/builder-shell-designsystem-fontpicker--docs) (Google list, Arabic filter,
  previews in both scripts, WOFF2 upload), then the type-scale tokens with live previews.
- **Radius & shadows** and **Spacing & widths**, each token with a live preview.

Every section stays mounted and is hidden when not chosen, so a draft typed in one section survives a
look at another. Font previews load only while Typography is open.

## One edit, one transaction

Every field keeps a draft while a person types and commits once, on blur or Enter. An external
write (a generation, an undo) discards the draft. With `onCommit` (from
`siteCommitFor(siteKernel)`), every edit is one labelled transaction:

| Edit | Steps | Label |
| --- | --- | --- |
| A token | `setDesignToken` | `Design token · radius lg` |
| A palette colour | `setPaletteColor` / `removePaletteColor` | `Palette colour · Sand` |
| A shade ramp | 11 × `setPaletteColor` | `Palette shades · Brand` |
| A family for a role | `setSiteFonts` + `setDesignToken` | `Font · Sans (body & headings) · Tajawal` |
| A font upload | `setSiteFonts` | `Upload font · Brand Sans` |

Without `onCommit` the panel is token-only and calls `onChangeToken` (the legacy contract).

## Refusals are announced

The door refuses a token that would make a declared pairing unreadable, and a palette colour that
is still used. The reason goes into a live region and is tied to the colour field, because a person
who has just typed a value is looking at the field, not at a banner.

Labels: `DESIGN_SYSTEM_PANEL_LABELS_EN` / `_AR`, plus `fontLabels` and `rampLabels` for the two
embedded editors. Pass `dir="rtl"` for the Arabic editor.
