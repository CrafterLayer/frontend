# FontPicker

The typography picker of the design-system editor (style-manager DESIGN.md §G, LIBRARIES.md §D).

- **Curated list.** About fifty SIL OFL families with the weights each actually ships (a wrong
  weight makes Google answer HTTP 400 and the face never loads). Arabic-capable faces include
  Cairo, Tajawal, IBM Plex Sans Arabic, Noto Kufi/Naskh Arabic, Almarai, Readex Pro, Rubik, Amiri,
  El Messiri, Changa, Reem Kufi, Markazi Text and Baloo Bhaijaan 2.
- **Search, style and an Arabic filter.** `arabicFirst` starts with the filter on.
- **Previews in both scripts.** Each family draws a Latin sample, and an Arabic sample only when it
  carries Arabic glyphs. Faces load from Google into the editor once per URL (`loadPreviews`).
- **Upload.** A `.woff2` of at most 600 kB, checked by its `wOF2` signature before it is encoded
  as `data:font/woff2;base64,…`. The person names the family and the weight (or a variable range)
  and is reminded they need the right to use it.
- **Never writes.** `onPick` and `onUpload` hand the family to the host, which commits
  `setSiteFonts` and the role's `setDesignToken` as one transaction.

Labels: `FONT_PICKER_LABELS_EN`, `FONT_PICKER_LABELS_AR`.
