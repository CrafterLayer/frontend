# IconRail

`IconRail` is the builder shell's primary navigation. It owns the editor's one dark surface and
keeps the main sections at inline-start, utility sections pinned to the block-end, and caller-owned
account content below those utilities.

## Usage

```tsx
import { IconRail } from '@craftkit/builder-shell';

<IconRail
  items={[
    { id: 'pages', label: 'Pages', icon: <PagesIcon /> },
    { id: 'blocks', label: 'Blocks', icon: <BlocksIcon /> },
  ]}
  secondary={[{ id: 'settings', label: 'Settings', icon: <SettingsIcon /> }]}
  activeId="pages"
  onSelect={(id) => {
    openSection(id);
  }}
  account={<AccountAvatar />}
/>;
```

The caller owns selection state and supplies 16- or 18-pixel inline SVG icons. Labels are always
shown in top-layer tooltips on hover or keyboard focus. Escape dismisses a tooltip.

## API

| Prop        | Type                   | Default            | Notes                                       |
| ----------- | ---------------------- | ------------------ | ------------------------------------------- |
| `items`     | `readonly RailItem[]`  | required           | Primary items in visual and DOM order       |
| `secondary` | `readonly RailItem[]`  | `[]`               | Utility items pinned above the account      |
| `activeId`  | `string`               | none               | Matching item receives `aria-current`       |
| `onSelect`  | `(id: string) => void` | none               | Fires from native button activation         |
| `account`   | `ReactNode`            | none               | Caller-owned account content at block-end   |
| `label`     | `string`               | `Builder sections` | Accessible name for the navigation landmark |

`RailItem` contains a stable `id`, a visible `label`, and a caller-supplied `icon`.

## Accessibility

The navigation landmark contains real lists of native `button` elements. Each icon wrapper is hidden
from assistive technology and each button carries its label as its accessible name. Native Tab,
Enter, and Space behavior is preserved; the component adds no roving focus or custom keyboard
handler. Focus appearance comes from the builder theme's shared `.bldr-root :focus-visible` rule.
The active destination alone exposes `aria-current="page"`. Every navigation item is a quiet
`ChromeButton` with a stable tile height of `--bldr-hit-target-min`. The primary list scrolls when
the available height is short. Focus uses the theme focus-ring color on the panel-colored rail.

## RTL and theming

All geometry uses logical properties, so the rail mirrors to inline-end when inherited direction is
RTL without a second stylesheet.

<Canvas of={IconRailStories.RightToLeft} />

Every colour, radius, type size, spacing, rail width, hit target, and transition comes from the
`@craftkit/builder-theme` contract. Hover, active, and pressed states change colour only; no item
changes size or scales.

The compact rail uses icon-only buttons; its width is the hit target plus inline padding. Tooltips
use the browser popover top layer to avoid clipping in a scrollable navigation list.
