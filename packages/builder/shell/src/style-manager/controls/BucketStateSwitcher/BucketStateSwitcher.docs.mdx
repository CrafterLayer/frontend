# BucketStateSwitcher

Decides where a style edit applies (style-manager DESIGN.md §A.5, §A.7).

- **Bucket** (desktop-first): Desktop writes unprefixed classes, Tablet `max-lg:`, Mobile `max-md:`
  and a custom bucket `max-[Npx]:`. Custom breakpoints already used on the page are listed so they
  can be picked again. When the device is free-width at a width that is not a preset (1280, 834,
  390), an "Edit at ≤ N px" button creates that custom bucket.
- **State**: Default, Hover, Focus (`focus-visible:`), Active, Open and Group hover.

Both rows are `ChoiceGroup` radio groups (one tab stop each, arrows mirrored for RTL). The host keeps
the bucket in step with the DeviceBar; this control only reports choices.

Labels: `BUCKET_STATE_SWITCHER_LABELS_EN` (default) and `BUCKET_STATE_SWITCHER_LABELS_AR`.
